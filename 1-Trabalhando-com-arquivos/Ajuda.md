# 📖 Ajuda e Manuais do Sistema (`--help`, `man`)

Comandos essenciais para consultar a documentação oficial, parâmetros disponíveis e exemplos de uso diretamente no terminal, sem precisar sair da linha de comando.

## Comandos

### `ls --help`
Exibe um resumo rápido diretamente no terminal com a sintaxe e todas as opções (*flags*) suportadas pelo comando `ls`. 
* **Dica:** A opção `--help` funciona para a grande maioria dos comandos no Linux (ex: `mkdir --help`, `rm --help`).
```bash
ls --help
```

### `man clear`
Abre a página completa do **manual** (*Manual Pages*) do comando `clear` em um leitor paginado. Mostra a descrição detalhada, sinopse, opções e comandos relacionados.
* **Navegação no `man`:** Use as setas ou `Espaço` para rolar, `/` para pesquisar uma palavra e pressione **`q`** para sair e voltar ao terminal.
```bash
man clear
```
